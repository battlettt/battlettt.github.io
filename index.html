SentinelScan

Chrome Extension · v1.1

A Chrome extension that gives any website a security report card on demand. It combines passive header and config analysis, a JS-source secrets scanner, Subresource Integrity (supply-chain) checking, and local historical drift detection — flagging when a site's security posture changes between visits, which most one-shot graders never catch. Every finding is explained in MITRE ATT&CK technique terms, and each header issue ships with a paste-ready Express and Nginx fix.

Memory Time

Live

A shared spaced-retrieval app for families supporting a loved one with memory loss. The training schedule follows real SRT clinical practice rather than generic flashcard spacing: misses are re-asked soon but never drilled back-to-back, intervals grow on success and reset on a miss, and a run of misses eases the session off instead of pushing harder. Any family member can add a memory — photo, voice note, question — from their own phone.
