Memory Time

A shared spaced-retrieval app for families supporting a loved one with memory loss. The schedule follows real SRT clinical practice, not generic flashcard spacing: misses are re-asked soon but never drilled back-to-back, intervals reset on a miss, and a run of misses eases the session off rather than pushing harder.
