03 / network scanning

Porthawk

Go · shipped v1.3

A concurrent TCP port scanner with banner grabbing, written in Go with zero dependencies. Point it at your own network to find every listening service (a forgotten FTP daemon, a Redis bound to 0.0.0.0) and identify it from the banner it sends back. HTTPS ports get a real TLS handshake that records the certificate and cipher and flags expired certs, and -diff spots new or changed services week over week. v1.3 adds CI with race and fuzz testing, plus a -rate cap for gentle scans of fragile devices.

AuthLog Sentinel

Go · shipped v1

Point it at an SSH auth log and it ranks the IPs trying to break in: failed logins grouped by source inside a sliding window, with a score that weights distinct usernames so credential stuffing stands out from one password guessed many times. 04 / python mlops

Driftwatch

Drift detection · shipped v0.2

Driftwatch fits a reference distribution once, then scores every new batch column by column with PSI, KS tests, Jensen-Shannon divergence and chi-square, flags correlation shifts, and tracks accuracy, log-loss or R² once labels arrive. A --fail-on flag turns drift or decay into a CI exit code, and everything runs offline.

13 / typescript ml

Smishield

SMS smishing detection · shipped v1

Smishield trains a TF-IDF and logistic regression classifier on 5,574 real labeled SMS messages, then runs the whole detector in your browser: paste a message and it returns a verdict, a confidence percentage, and the plain-English signals behind it, like a shortened URL or urgency wording. The TypeScript scorer matches scikit-learn to within 1e-9 on a held-out set, and nothing you paste ever leaves the device. The data is 2012-era, so modern parcel-fee and bank-alert smishing can still slip past it, and the page says so.

14 / python applied ai

Course Compass

Grounded study companion · shipped v1

Course Compass turns your own course notes into cited answers, quizzes, and a spaced-review plan. Ask a question and it retrieves the relevant chunks first, then an LLM answers only from those chunks, with every claim cited and an honest refusal when nothing matches well enough. Quizzes are generated from the notes too, with wrong options taken from your other notes, never invented, and misses feed a study plan that spends the most time on your weakest topics. With no API key it runs a clearly labelled offline fallback instead of pretending to be the model. It has since grown school features: layered lecture simplifications, real-life examples labelled grounded or illustrative, a due-today digest with calendar export, per-topic progress trends, and a rapid-fire cram mode, with its prompts evaluated against a real model rather than a mock.

10 / typescript devtools

Semver Guard

Breaking-change detection · shipped v6

Semver Guard diffs the public API of a TypeScript package between two snapshots and flags exactly the changes that break downstream users: removed exports, changed signatures, dropped class and interface members, altered type aliases, removed enum members. It exits non-zero when it finds one, so it can gate a release in CI before the version number is a lie. Safe changes, like a new export or an internal-only edit, pass silently.

11 / python data pipeline

Transit Pulse

GTFS reliability analytics · shipped v3

Transit Pulse joins a GTFS static schedule with GTFS-Realtime observations in DuckDB and reports what riders actually experienced: on-time performance per route, headway adherence on frequent service, and bunching events where two vehicles arrive together instead of evenly spaced. Cancelled trips and unobserved stops are reported separately, never silently counted as on time. Output is a metrics file plus a self-contained HTML dashboard that renders with no network.

Unclaimed Property Compliance

Research toward an AI-native service for US state unclaimed property compliance, wedged on Delaware VDA response.

Companies that hold money owed to someone else, such as uncashed payroll checks, stale vendor credits or forgotten customer balances, must eventually hand it to the state. It is published with its corrections intact. Two load-bearing claims from the original screen were wrong, and the build log records both. kept on the record The field is contested, and state holder data is not public, so every figure here is sourced rather than assumed.
