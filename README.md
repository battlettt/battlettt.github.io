# battlettt.github.io

Personal landing page — a single static `index.html`, no build step, no dependencies.

Served at **https://battlettt.github.io/**

## Editing

Edit `index.html` and push to `main`. GitHub Pages redeploys in ~30 seconds.

## Notes

- `.nojekyll` is present so GitHub serves the files as-is instead of running them through Jekyll.
- This is the **user site** (repo named `battlettt.github.io`), which serves at the domain root.
  It does not conflict with the project site at `/cybersecurity-portfolio/`, which is published
  from its own repository.
